Instrucciones de ejecución local (XAMPP)
1. Copiar esta carpeta en `C:\xampp\htdocs\tecnostock\`.
2. Iniciar **Apache** y **MySQL** desde el panel de control de XAMPP.
3. Abrir `http://localhost/phpmyadmin/`, crear una base de datos llamada `tecnostock_db` e importar el archivo `tecnostock_db.sql`.
4. Acceder al sistema desde el navegador en `http://localhost/tecnostock/`.
